# 库存记录

本目录保存袜子产品的库存主记录。对于同一产品，原则上只维护一个固定文件；历史变化记录在该文件内部，不重复创建日期文件。

## 当前记录

- [2026下半年冰冰袜库存包装统计](2026下半年冰冰袜库存包装统计.md)：当前唯一库存主记录，包含自 2026-09-06 至 2026-09-20 的更新内容。
- [2026下半年下机白胚半成品统计](2026下半年下机白胚半成品统计.md)：2026 年 7—12 月生产主账，历史记录与 2026 年 10—12 月月度区块持续保留在同一文件。
- [2027全年下机白胚半成品统计](2027全年下机白胚半成品统计.md)：2027-01-01 至 2027-12-31 独立主账模板，预先建立全年汇总、12 个月度表和个人累计区块，避免跨年串账。

## 维护方法

1. 同一产品只建立一个固定库存文件，例如 `2026下半年冰冰袜库存包装统计.md`。
2. 增加颜色或修改数量时，直接更新“颜色库存明细”和顶部汇总。
3. 每次修改“更新日期”，并在同一文件的“更新记录”唯一历史表格末尾连续追加一行；不得用空行拆表，也不另建历史副本。
4. 每次记录尽量写明产品、颜色、库存阶段、数量、记录日期和来源。
5. 生产、出货和剩余库存要分开记录，避免把生产量误当成可销售库存。
6. 如果库存数据与旧记录冲突，保留旧记录，并在“更新记录”中追加更正行说明原因；更正不删除原事件，也不重复入账。

## 生产台账跨月与跨年维护

1. 生产日期决定主账文件：2026 年记录写入 2026 下半年主账；2027 年记录写入 2027 全年主账，不按上传时间或确认时间跨年归档。
2. 每月个人累计、月度汇总和每日汇总只统计各自 `YYYY-MM` 或 `YYYY-MM-DD` 范围；全年汇总只统计文件标题所声明的年度周期。
3. 2027 模板中的“核实”表示还没有收到该产品的数量，不等于 0；收到明确 0 后才写入 0。
4. 上传前运行 `guard_production_ledger.py`。guard 会从候选台账中的月份/年度标题动态识别校验范围，同时检查旧记录、来源/确认消息及个人累计，兼容现有 2026 旧账。
