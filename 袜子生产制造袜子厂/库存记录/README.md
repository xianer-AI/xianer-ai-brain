# 库存记录

本目录保存袜子产品的库存主记录。对于同一产品，原则上只维护一个固定文件；历史变化记录在该文件内部，不重复创建日期文件。

## 当前记录

- [2026下半年冰冰袜库存包装统计](2026下半年冰冰袜库存包装统计.md)：当前唯一库存主记录，包含自 2026-09-06 至 2026-09-20 的更新内容。

## 维护方法

1. 同一产品只建立一个固定库存文件，例如 `2026下半年冰冰袜库存包装统计.md`。
2. 增加颜色或修改数量时，直接更新“颜色库存明细”和顶部汇总。
3. 每次修改“更新日期”，并在同一文件的“更新记录”唯一历史表格末尾连续追加一行；不得用空行拆表，也不另建历史副本。
4. 每次记录尽量写明产品、颜色、库存阶段、数量、记录日期和来源。
5. 生产、出货和剩余库存要分开记录，避免把生产量误当成可销售库存。
6. 如果库存数据与旧记录冲突，保留旧记录，并在“更新记录”中追加更正行说明原因；更正不删除原事件，也不重复入账。
