# 2026下半年下机白胚半成品统计
> 白胚半成品下机与烤边/烤头生产统计主记录。数量单位：双。

创建日期：2026-09-19
统计周期：2026下半年
统计口径：生产日按每日 07:00 至次日 07:00 计算，避免晚班被拆成两天。

## 记账规则

- 每个人、每条记录单独入账，禁止合并覆盖原始记录。
- A/B 为下机工，记录“下机”数量。
- C 为烤边/烤头工人，记录“烤边”或“烤头”数量。
- A 早班时间：07:00-19:00。
- B 晚班时间：19:00-次日 07:00。
- C 白天为主，时间不固定；如加班，按实际报数计件。
- 产品类别先固定为：棉堆堆袜、冰冰袜、小腿袜、魔术袜。
- 每日汇总需分别统计：按产品、按工序、按工人，并计算下机合计。

## 员工群内上报格式

员工可按简短格式上报：

```text
A 冰冰袜 下机 3200 双
B 棉堆堆袜 下机 2800 双
C 冰冰袜 烤边 3000 双
C 小腿袜 烤头 1800 双
```

如需备注，可追加在最后：

```text
A 冰冰袜 下机 3200 双 备注：断线停机30分钟
```

## 查询规则

- 工人在群里或私聊发送“查我的本月计件”，可查询自己当月计件数量。
- A 只查询 A 自己的数量；B 只查询 B 自己的数量；C 只查询 C 自己的数量。
- 贤二可查询所有工人、任意日期、任意月份、按产品/工序/工人汇总。
- 如在群里公开查询，回复会在群里可见；如需不让其他工人看到，应私聊查询。
- 支持查询口令示例：

```text
查我的本月计件
查A本月
查B 2026年9月计件
查C 9月烤边数量
```

## 月度汇总规则

月底或用户要求时，按工人生成月度计件总结：

- A：统计本月下机数量，并按棉堆堆袜、冰冰袜、小腿袜、魔术袜分产品汇总。
- B：统计本月下机数量，并按棉堆堆袜、冰冰袜、小腿袜、魔术袜分产品汇总。
- C：统计本月烤边/烤头数量，并按产品和工序分别汇总。
- 月度总结需包含：记录天数、最后更新日期、按产品小计、按工序小计、个人月合计。
