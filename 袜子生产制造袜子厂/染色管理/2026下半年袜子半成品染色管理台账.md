# 2026下半年袜子半成品染色管理台账
> 记录袜子半成品的染色颜色、额外增加颜色、数量、染色费及流转状态。所有数量单位：双。

创建日期：2026-09-20
统计周期：2026下半年
数量单位：双
金额单位：元

## 记账口径

- 每条染色记录单独入账，不覆盖历史记录。
- 袜子数量统一按“​​双”统计，不使用“包”作为数量单位。
- 下机、进仓、送染、染色完成、染回仓库是不同节点，日期分别记录；不同日期不能合并成一个日期。
- “额外增加颜色”单独标记，记录新增颜色名称、数量、单位染色费和总染色费。
- 染色总费用 = 染色数量（双） × 单位染色费（元/双）。
- 如果不同颜色或不同批次单价不同，必须分开记录，不能用一个单价覆盖全部记录。
- 染色费未提供时先留空，不凭 अनुमान填写；补充单价后再计算费用。

## 半成品流转节点

```text
下机 → 暂存 → 进仓 → 送染 → 染色完成 → 染回仓库
```

| 节点 | 说明 |
|---|---|
| 下机日期 | 半成品实际下机日期 |
| 进仓日期 | 实际进入仓库日期，可晚于下机日期 |
| 送染日期 | 实际送到染厂日期 |
| 染色完成日期 | 染厂完成染色日期 |
| 染回日期 | 染色半成品实际返回仓库日期 |
| 当前状态 | 下机后暂存、已进仓、已送染、染色中、已染回等 |
