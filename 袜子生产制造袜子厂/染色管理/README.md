# 染色管理

版本：V4.0  
生效日期：2026-09-28  
状态：正式规则模板，当前未录入虚构业务数据。

本目录是袜厂染色管理的唯一正式入口。以前版本中与本版本冲突的流程和口径，以 V4.0 为准。

## 管理口径

- 系统参与者只有老板和小数智能体。
- 染色厂工作人员不进入系统，不负责报数、确认或填表；实际拉货和送货仍由染色厂负责。
- 老板只负责报送真实事实，并在预览无误后回复“准确”。
- 小数负责识别、拆分、计算、预览、防重复、写账、汇总、对账和异常提醒。
- GitHub保存唯一正式账；飞书负责自然语言报数和查询；OpenClaw负责三者之间的自动执行。

## 核心流程

染色厂拉走货物/老板报送送染 → 预览 → 老板回复“准确” → 正式送染入账  
染色厂送回货物（一次或多次）/老板逐次报实际收到 → 预览 → 老板回复“准确” → 正式实收入账  
月底账单对账 → 预览 → 老板回复“准确” → 确认染色费  
付款 → 预览 → 老板回复“准确” → 正式付款入账

当前在染 = 累计正式送染 − 累计正式实收。

## 目录文件

- 染色管理规则.md：完整业务规则和自动化要求
- 染色流水.md：唯一原始事实账
- 当前在染状态.json：按产品和颜色汇总的当前状态
- 染色价格表.md：价格版本和生效日期
- 染色发回实收跟踪.md：实际实收预览、正式实收和异常记录（正文按实收口径）
- 染色费用汇总.md：预计费用、确认费用和待核对费用
- 染色付款记录.md：付款和核销记录
- 染色日汇总.md：日统计
- 染色月汇总.md：月统计
- 染色年汇总.md：年统计
- 染色健康检查.md：每日异常检查
- 染色月度结账.md：月底对账、结账和结账后更正

## 当前状态

2026-09-28：升级为 V4.0。旧版中与当前流程不一致的确认和计量口径已从正式规则和模板中移除。染厂仍负责实际拉货和送货；系统只记录老板确认的送染和每次实际实收。当前目录保留老板单人报数、分批实收、价格版本、对账、付款和防错结构。
