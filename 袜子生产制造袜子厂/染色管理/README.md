# 染色管理

本目录是袜厂染色模块的唯一正式入口。

## 管理目标
- 货物：进染厂 → 染厂发回 → 家里实收 → 当前在染 → 已发未收 → 异常。
- 费用：产品+颜色 → 计费单位 → 单价 → 染色费 → 对账 → 已付 → 未付。

## 核心原则
1. 每次进厂、发回、实收保留真实流水，不覆盖历史。
2. 同一“染厂 + 产品 + 颜色”建立动态在染池，不猜某次发回属于哪一天进厂。
3. 当前在染 = 累计进厂 - 累计染厂发回。
4. 已发未收 = 累计染厂发回 - 累计家里实收。
5. 日/月/年统计从流水汇总，跨月余额结转。
6. 染色费按“染厂 + 产品 + 颜色 + 计费单位 + 单价 + 生效日期”管理，不默认统一按包。
7. 价格不明时正常记货，费用标记“待定价”，不得猜价。
8. 异常不得强行入账或产生负余额。
9. 后续小数为染色模块唯一自动写入负责人；小文只读取汇总。
