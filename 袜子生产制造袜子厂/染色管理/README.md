# 染色管理

业务规则版本：V4.0  
工作台结构版本：V4.1  
生效日期：2026-09-28  

本目录是袜厂染色管理的唯一正式入口。GitHub main 保存唯一正式账，飞书负责老板报数和确认，OpenClaw 负责读取、预览、防重复、正式写入和回读核验。

## 核心流程

老板报送送染或实际实收 → 小数生成预览 → 老板回复“准确” → 正式写入 GitHub。

当前在染 = 累计正式送染 − 累计正式实收。染色厂工作人员不进入系统；系统只记录老板确认的送染和老板实际点清的每次实收。

## 当前目录结构

- 染色规则与价格.md：业务规则和版本化价格
- 染色流水.md：唯一原始事实账
- 当前在染状态.md：根据正式流水自动生成的状态表
- 染色厂往来明细.md：送染明细和分批实收明细
- 染色费用付款结账.md：费用、付款和月度结账
- 染色汇总与健康检查.md：日、月、年汇总和异常检查
- README.md：目录说明
