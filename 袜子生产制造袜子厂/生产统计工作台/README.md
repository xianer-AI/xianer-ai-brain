当前显示口径：徐超超、梅芳为“下机翻袜产量”（已翻好数量），李鸿玉、张小翠为“烤边产量”。“总产量（烤边）”只合计C/D实际烤边记录。两道工序分开核对数量，不增加单价、金额或外发交接。内部“下机／烤边”标识及两年度台账路径保持兼容。
