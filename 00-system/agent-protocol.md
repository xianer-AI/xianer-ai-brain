# Agent 工作协议

## 读取顺序

处理知识库任务时，先读取：

1. 根目录 `README.md`
2. 本文件
3. 与任务相关的目录 `README.md`
4. `03-index/index.md`
5. 目标主题下的事实页和知识页

## 新内容分流

原始内容先写入 `04-inbox/`，保留获取时间、来源或上下文、原文或摘要、不确定之处和可能的主题。

只有能说明信息来自哪里，或这是何时何地发生的观察，才进入 `01-facts/`。完成提炼、能够回答“这意味着什么”或“如何使用”的内容，才进入 `02-knowledge/`。

## 写入原则

- 不覆盖已有内容；更新前先阅读原文。
- 优先增量更新，避免为小改动重写整篇文档。
- 不确定的内容使用 `draft`，不要伪装成确定结论。
- 发现矛盾时保留双方记录，并明确写出冲突。
- 发现重复主题时优先建立链接或合并。
- 一次处理结束后更新 `03-index/index.md`，或在 `03-index/inbox-triage.md` 留下待办。

## 完成检查

- [ ] 文件放在正确层级
- [ ] 文件名符合命名规则
- [ ] 有来源、时间或上下文
- [ ] 区分事实、推断和建议
- [ ] 添加相关链接
- [ ] 更新索引或待办
- [ ] 没有把秘密、密码或个人敏感信息写入普通知识页
