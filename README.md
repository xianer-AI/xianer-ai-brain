# 个人 AI 知识库

这里是贤二的个人 AI 知识库，按主题整理项目资料、事实记录、方法和复盘。
各个独立项目的资料优先集中在自己的主题目录中，通用规则和导航放在编号目录中。

## 项目

- [袜子生产制造袜子厂](袜子生产制造袜子厂/README.md)：袜子选款判断、冰冰袜库存和生产相关资料。

## 知识库目录

- `00-system/`：知识库规则和 Agent 工作协议。
- `01-facts/`：跨项目的可追溯事实记录；项目专题资料可保存在自己的主题目录中。
- `02-knowledge/`：跨项目整理后的知识和方法；项目专题知识可保存在自己的主题目录中。
- `03-index/`：总索引和导航。
- `04-inbox/`：尚未整理的临时内容。
- `99-archive/`：归档内容。

新增内容请先保留来源和上下文。属于明确项目的内容，统一归档到对应项目目录；通用内容再放入事实层或知识层。
