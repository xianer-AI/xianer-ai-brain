# 生产统计运行源

这里保存生产统计工作台的正式运行代码、核对卡逻辑、待核实队列同步、测试和 2027 模板。GitHub `main` 是可审计的运行源。

运行时状态仍保存在用户目录的 OpenClaw state 目录中，包括 SQLite、待处理快照、回执和日志；这些文件不进入仓库。状态同步只把待核实队列和已确认出勤状态写入对应年度台账，不会把待核实日期当成生产记录，也不会增加产量或累计天数。

## 校验

```bash
python3 -m unittest discover -q
python3 -m py_compile *.py
```

服务启动后会定期把本地待核实队列投影到 2026、2027 台账，并在远程回读一致后记录提交回执。
