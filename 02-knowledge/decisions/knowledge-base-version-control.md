# 知识库版本控制与远程同步

## 结论

知识库发生变动后，默认由 Agent 自动完成版本提交并推送到远程仓库。

## 适用范围

- 仅包含本次知识库任务实际修改的文件。
- 默认提交到当前分支，并推送到远程 `origin`。
- 不包含其他项目、其他目录或用户无关的未提交改动。

## 操作约定

1. 修改完成后检查差异和敏感信息。
2. 只暂存本次任务涉及的文件。
3. 创建简短、可读的提交说明。
4. 推送到当前分支的 `origin`。
5. 如果推送失败，保留本地提交并说明失败原因。

## 来源与时间

- 来源：用户在 2026-09-13 的明确偏好。
- 记录日期：2026-09-13。
